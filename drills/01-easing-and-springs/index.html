Motion Studio / Drill 01

Easing and springs

The same move, four ways. The curve decides whether an interface feels quick, sluggish or alive.

What this teaches

  • Ease-out for anything entering or responding to the user. The motion happens at the start, right when the click lands, so the interface feels instant.
  • Ease-in is for things leaving, and even then it is rarely right in UI: the first frames barely move, which reads as lag.
  • Keep UI moves short: 150 to 300 ms for small elements. Narrative motion in a lesson can be slower because the viewer is watching, not waiting.
  • Springs are physics, not curves. They have no fixed duration; they carry velocity, so an interruption flows instead of snapping. Use them for anything the user can grab, toggle or interrupt.

The lines that matter

// A curve: the browser's own engine (Web Animations API)
el.animate([{ transform: `translateX(${from}px)` }, { transform: `translateX(${to}px)` }],
  { duration, easing: 'cubic-bezier(0.22, 1, 0.36, 1)', fill: 'forwards' });

// A spring: Motion tracks velocity, so a retarget mid-flight is smooth
animate(el, { x: to }, { type: 'spring', visualDuration: duration / 1000, bounce });
