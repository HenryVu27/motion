Scrollytelling

A graphic holds still while the text scrolls past it. Each paragraph is a state; one of them is tied to the scrollbar itself.

This is the pattern The Pudding and the New York Times use for data stories. The mechanism has three parts: a sticky graphic, a column of steps, and something that reports which step is on the trigger line. Scroll on.

What this teaches

  • Let CSS do the sticking. position: sticky on the graphic is cheaper and less fragile than pinning with JavaScript; ScrollTrigger is used only to report which step is on the line and how far through it you are.
  • Model the graphic as states, not as a script. Each step names a layout, and crossing the line from either direction tweens to that layout from wherever the dots are now. Fast scrolling, scrolling back and reloading mid-page all land in the right place.
  • Scrub only what deserves a hand on it. Discrete steps read as chapters; a scrubbed step reads as a process. Give the scrubbed step extra height and keep its text sticky so the reader has room to drive it.
  • On phones, stack instead of splitting. The graphic sits on top with an opaque background and the steps slide under it; the trigger line moves down to the middle of the reading area.
  • Keep one thing constant across states. The accent group is the thread the reader follows through every rearrangement.

The lines that matter

// One trigger per step. Any crossing re-derives the state from scroll position:
// the current step is the last one whose top has passed the line.
const triggers = steps.map((step) => ScrollTrigger.create({
  trigger: step, start: 'top 60%', end: 'bottom 60%',
  onEnter: sync, onLeave: sync, onEnterBack: sync, onLeaveBack: sync,
}));
function sync() {
  const y = triggers[0].scroll();
  activate(triggers.findLastIndex((t) => y >= t.start));
}

// The scrubbed step: progress 0..1 becomes how far each dot has walked.
ScrollTrigger.create({
  trigger: scrubStep, start: 'top 60%', end: 'bottom 60%',
  onUpdate: (self) => active === SCRUB && walk(self.progress),
});

// Every move, discrete or scrubbed, retargets from where the dots are now.
