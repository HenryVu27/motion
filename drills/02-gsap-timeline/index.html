Motion Studio / Drill 02

GSAP timeline choreography

One timeline, many tweens, placed by position parameters. The whole sequence becomes a single object you can play, reverse and scrub.

What this teaches

  • Build the sequence once, then drive it. A paused timeline is a value from 0 to 1. Play, reverse, scrub and scroll are just different hands on the same dial, so there is no state to keep in sync.
  • Place tweens relative to each other, never by absolute seconds. "<" means with the previous tween, "-=0.2" overlaps it, a label names a beat. Change one duration and everything after it moves along.
  • Overlap is what makes choreography feel continuous. Starting the next tween 0.2 s before the last one ends removes the dead beat between steps.
  • Draw lines from source to target. DrawSVG reveals a path along its own direction, so the order of points in d becomes the direction of the argument. No arrowheads needed.
  • Put defaults on the timeline (defaults: { duration, ease }) so every tween shares one rhythm and only the exceptions are spelled out.

The lines that matter

gsap.registerPlugin(DrawSVGPlugin);
const tl = gsap.timeline({ paused: true, defaults: { duration: 0.5, ease: 'power2.out' } });

tl.from('.premise', { scale: 0, transformOrigin: '50% 50%', stagger: 0.15 })
  .addLabel('links', '-=0.1')
  .from('#l-p1, #l-p2', { drawSVG: '0%', duration: 0.7, stagger: 0.1 }, 'links')
  .from('.lemma', { scale: 0, ease: 'back.out(2)' }, '-=0.2')   // overlap
  .from('#l-lemma', { drawSVG: '0%' })                            // after the last
  .from('#l-p3', { drawSVG: '0%', duration: 0.9 }, '<')          // with the last
  .addLabel('land')
  .from('.conclusion', { scale: 0, ease: 'back.out(2)' }, 'land-=0.15');

scrub.oninput = () => tl.pause().progress(scrub.value / 1000);
