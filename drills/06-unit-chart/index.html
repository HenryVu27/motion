Motion Studio / Drill 06

Making big numbers felt

A million is an abstraction; five thousand dots are a crowd. Count in units the eye can see, then move the units, never the bars.

What this teaches

  • State the unit on the figure, every time. "1 dot = 1,000 people" is the sentence that turns a texture into a quantity. Pick the unit so the total lands in the low thousands: enough to feel like a crowd, few enough to draw every frame.
  • Hold the dot size fixed across layouts. Compute one cell size that fits the most demanding layout and use it everywhere. If dots shrink when they regroup, the reader's sense of quantity is quietly lied to.
  • Compute every layout up front, then only interpolate. A layout is an array of target positions. A transition is from, to, a start time and a per-dot delay; the frame loop just evaluates the ease.
  • Stagger by position, not by index. A delay that follows each dot's destination left to right, plus a little noise, reads as a flow. A delay by array index reads as random flicker.
  • One canvas, batched fills. Five thousand DOM nodes would choke on layout; on canvas they are one path per color per frame. Retarget from the current position so an interrupted move never snaps.

The lines that matter

// Retarget: every dot starts from where it is now, with its own delay
for (const d of dots) {
  [d.fx, d.fy] = position(d, now);
  [d.tx, d.ty] = layout[d.slot];
  d.delay = 0.55 * (d.tx / width) + 0.2 * Math.random();
}

// Each frame: one ease per dot, then one fill per color
const p = easeOutCubic(clamp((now - start - d.delay) / DURATION));
ctx.rect(d.fx + (d.tx - d.fx) * p, d.fy + (d.ty - d.fy) * p, size, size);

Learned from

Neil Halloran's The Fallen of World War II (2015), a data documentary where small figures standing for the dead pile up, split by country and regroup as the narration moves on; and Slate's animated interactive of the Atlantic slave trade by Andrew Kahn and Jamelle Bouie (2021), where every slave ship is a dot sized by the number of people it carried, so the scale is seen before it is read.
