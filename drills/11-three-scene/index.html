Motion Studio / Drill 11

A three.js scene

A small temple of boxes and cylinders, and a camera that walks between three viewpoints. The basics, done the way they hold up later.

What this teaches

  • Size to the box, not the window. A ResizeObserver on the stage calls renderer.setSize(w, h, false) and updates the camera's aspect and projection. The false leaves the canvas CSS alone so the page layout stays in charge. Cap setPixelRatio at 2: a 3x phone screen would cost 2.25 times the pixels for detail nobody sees.
  • Resizing is not rebuilding. The renderer, geometries and materials are made once; a resize only changes the drawing buffer size and the projection. Disposal is for teardown: geometries, materials, render targets and the renderer each hold GPU memory that garbage collection cannot see, so free them when a figure is removed or hot reloaded.
  • Move the target, not just the camera. Tween a lookAt point alongside the position with the same duration and call camera.lookAt(target) every frame. Tweening position alone makes the view swing around at the end. To make a straight path arc, give the height its own ease: leading on the way up, lagging on the way down.
  • Render only what changed. The scene is static, so the loop draws only when a tween or a resize marks it dirty, and the shadow map is rendered once (shadowMap.autoUpdate = false). The loop itself stops when the figure leaves the screen.
  • Draw calls, not triangles, are the budget. The 26 columns are one InstancedMesh: one geometry, one material, a matrix per copy, one draw call. Soft light is a hemisphere light for the sky and ground plus one shadow-casting sun with PCF filtering and a blur radius; fog set to the page color dissolves the horizon into the paper.

The lines that matter

renderer.setPixelRatio(Math.min(devicePixelRatio, 2));
new ResizeObserver(() => {
  const { width, height } = stage.getBoundingClientRect();
  renderer.setSize(width, height, false);
  camera.aspect = width / height;
  camera.updateProjectionMatrix();
}).observe(stage);

// position and look-at target travel together; height takes its own ease
gsap.to(camera.position, { x, z, duration: 1.8, ease: 'power2.inOut', onUpdate: markDirty });
gsap.to(camera.position, { y, duration: 1.8, ease: goingUp ? 'power3.out' : 'power3.in' });
gsap.to(target, { ...look, duration: 1.8, ease: 'power2.inOut' });

loop(() => { if (dirty) { camera.lookAt(target); renderer.render(scene, camera); } }, stage);
