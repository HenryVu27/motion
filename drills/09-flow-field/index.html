Motion Studio / Drill 09

Flow field

Thousands of particles, one rule: read an angle from noise, take a step. The trails they leave become the picture.

What this teaches

  • Noise, not random. Math.random() gives each point an unrelated angle, so particles jitter in place. Simplex noise is smooth: nearby points get nearby angles, so paths curve and neighbors flow together. The noise scale is the only real design knob; it sets how big a current is in pixels.
  • Map the noise past one turn. Simplex output sits mostly near zero (standard deviation about 0.43 here), so angle = n * PI leans right. Multiplying by a full turn, n * TAU, wraps the tails around and spreads directions evenly.
  • Accumulate or fade. Never clearing the canvas and drawing at low alpha turns density into tone: where paths converge the paper darkens. Fading instead paints a translucent background rectangle each frame. Make that alpha frame-rate independent (1 - (1 - a) ** (dt * 60)), and expect faint ghosts: 8-bit blending rounds tiny alpha steps to zero, so old trails never quite vanish.
  • Batch the strokes. One beginPath, a moveTo/lineTo pair per particle, one stroke. Thousands of separate strokes would cost thousands of draw calls.
  • Curl noise keeps particles apart. An angle field has sinks where paths pile into a few dark veins. Rotating the noise gradient by 90 degrees gives a divergence-free field: particles slide along the noise contours and never bunch up.

The lines that matter

const noise3D = createNoise3D(seededRandom);   // simplex-noise 4: pass a PRNG to reproduce a seed

// angle field: smooth input, so neighbors agree
const a = noise3D(x * scale, y * scale, z) * TAU;
p.x += Math.cos(a) * speed;  p.y += Math.sin(a) * speed;

// curl field: rotate the gradient 90 degrees, divergence-free
const dx = (noise3D(X + e, Y, z) - noise3D(X - e, Y, z)) / (2 * e);
const dy = (noise3D(X, Y + e, z) - noise3D(X, Y - e, z)) / (2 * e);
p.x += dy * speed;  p.y -= dx * speed;
