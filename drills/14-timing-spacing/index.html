Motion Studio / Drill 14

Timing and spacing

A drop of dew, twice. Timing is how long each thing takes. Spacing is how far it moves between drawings. Almost all of the life is in the spacing.

What this teaches

  • Spacing is the physics. A falling thing covers 1, 3, 5, 7 units on successive drawings (distance grows with the square of time). An ease-in-out curve brakes at the end; it reads as a hand placing the drop, not gravity dropping it. Choose spacing from what is pushing the thing.
  • Anticipation tells the eye where to look. Before it falls the drop gathers, stretches and necks down at the tip. The viewer knows something is about to happen a few drawings before it does, so the fall lands instead of surprising.
  • Squash and stretch keep the volume. Fast means long, impact means flat and wide, and right after release it overshoots into a squat and wobbles. Width shrinks when height grows (stretch s gives width r / √s, height r · s), so it reads as liquid, not rubber.
  • Follow-through belongs to the other thing. The leaf sags under the weight, then springs back past rest and settles on a damped spring. The drop leaving is shown by the leaf, too.
  • Secondary action finishes the beat. The splash crown and rings arrive after the main event and fade on their own clocks. They are why the impact has weight.
  • Moving holds. Even while it waits, the drop swells and trembles slightly. A perfectly still drawing inside a moving film looks like the film stopped.

The lines that matter

// State is a pure function of time, so onion skin = ask about earlier drawings
const drop = dropAt(t);                      // { x, y, r, stretch, neck }
for (let k = 1; k <= 6; k++) ghost(dropAt(t - k / 12));

// Gravity spacing versus an easing curve
y = top + (G * k * k) / 2;                   // falls: 1, 3, 5, 7 ...
y = top + easeInOut(k / dur) * fall;          // placed: slow, fast, slow

// Squash and stretch, area kept
width = r / Math.sqrt(stretch); height = r * stretch;
