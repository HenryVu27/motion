Signed distance shader

Shapes with no vertices. Every pixel asks one question, how far am I from the edge, and the answer draws the picture.

What this teaches

  • A shape is a function. A signed distance function returns how far a point is from the edge: negative inside, zero on it, positive outside. A circle is length(p) - r. Because the value is a distance, outlines, glows, offsets and rounding all come for free (sdBox(p) - 0.04 rounds the box's corners).
  • Combining shapes is arithmetic. min(a, b) is union, max(a, b) intersection, max(a, -b) subtraction. Quilez's smooth minimum blends the two fields where they are within k of each other, which is the melting you see. Mixing a box and a circle field morphs one into the other; the result is no longer an exact distance but stays safe to shade and march.
  • Antialias with fwidth. fwidth(d) is how much the distance changes across one pixel, so dividing by it converts distance into pixels. Edges and iso-lines then stay exactly 1 to 2 pixels wide on any screen and at any zoom, with no multisampling.
  • Resolution-independent units. Map pixels to (2 * fragCoord - res) / res.y: centered, y up, the stage is two units tall. Shapes and the pointer use the same units, so nothing depends on screen size or pixel ratio.
  • Raw WebGL2 for a single full-screen pass. A fragment shader on one quad needs no scene graph, camera or matrices, so three.js would add weight and hide the pipeline. Here it is one oversized triangle placed by gl_VertexID, no buffers, and a handful of uniforms; the token colors go in as uniforms and come out unchanged. Reach for three.js when the shader has to live inside a 3D scene.

The lines that matter

float sdCircle(vec2 p, float r) { return length(p) - r; }
float sdBox(vec2 p, vec2 b) {
  vec2 d = abs(p) - b;
  return length(max(d, 0.0)) + min(max(d.x, d.y), 0.0);
}
float smin(float a, float b, float k) {
  float h = max(k - abs(a - b), 0.0) / k;
  return min(a, b) - h * h * k * 0.25;
}

float d = smin(mix(box, circle, morph), sdCircle(p - uMouse, 0.24), uK);
float edge = clamp(1.5 - abs(d) / fwidth(d), 0.0, 1.0);   // 2 px edge, any resolution
col = mix(col, uAccent, edge);
